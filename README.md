## What the list is saying

This is an **agent-skills day**, not a diversified engineering chart.

1. **Skills and harnesses dominate.** skills (Matt + Anthropic), ponytail, ECC, humanizer, caveman, diagram-design, Hermes, OpenCode. High star counts on skill folders are herd behavior, not a quality signal.
2. **Local / owned compute.** Magnitude (local inference), VoiceStudio (local voice), TimesFM and Miles (research/training).
3. **Things that are not agents.** `{fmt}` is the only classic library. RenoDX is a game-graphics tool. Those two will outlive the skill-pack fashion cycle.

## What this repo did *not* deploy

These 17 projects are different stacks (Shell skills, C++ libs, Python research, HLSL mods, Kotlin catalogues). Standing all of them up would need GPUs, messaging gateways, and in two cases would be the wrong thing to host.

This repository deploys the **briefing**. Individual homepages and try-links are in `index.html`.

We did not deploy or mirror **exploitarium** (exploit PoCs) or **fanqiang** (circumvention tooling).
